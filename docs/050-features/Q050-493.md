# Q050-493 Warp controls for launcher audio cells in the GUI

Starting state (verified): Q050-013 shipped the engine for an audio cell's `gain_db`, `transpose`, `detune`,
`loop_start` / `loop_length`, `warp` and `warp_bpm` (`docs/050-features/Q050-013.md`), but the cell's right-click menu
only had Edit Cell..., a generic `session.set_slot` form that showed those fields blank (not at the cell's values), and
the cell's face showed none of them. Q050-013's known limits recorded the warp GUI as missing.

## Built
- **Playback and Warp** submenu on an AUDIO cell's right-click menu (`src/gui/SessionGridMenus.cpp`,
  `addPlaybackEntries`; MIDI and empty cells do not get it):
  - *Gain, Pitch, Loop and Warp...* - the `session.set_slot` CommandForm with every playback field `set_slot` accepts
    (`gain_db`, `transpose`, `detune`, `loop_start`, `loop_length`, `warp`, `warp_bpm`, `ram`) pre-filled with the cell's
    `session.get_state` values;
  - *Warp to Song Tempo* On / Off and *RAM Mode* On / Off (`addCommandChoices` on the `warp` / `ram` booleans);
  - *Reset Gain, Pitch, Loop and Warp* - one `set_slot` with every one of those fields at its default (RAM mode kept).
  Every entry runs the registered `session.set_slot` through the ControlRegistry - the command an agent calls on the
  socket / MCP - so the GUI and the agent path are the same command, one journal checkpoint, one undo step.
- **The cell's display** (`src/gui/SessionGridCells.cpp` `playbackBadge` / `playbackWords`,
  `src/gui/SessionGridView.cpp` `readPlayback` / `paintPlayback`): an audio cell whose settings are off their defaults
  shows them after its name - `-6.0dB +12st +50ct ⟲ W128` - and its accessible name and tooltip say them in words
  ("gain -6.0 dB, transposed +12 semitones, ..."). Cells at every default look exactly as before.
- Manual: `data/manual/index.html`, "The launcher", paragraph "An audio cell's gain, pitch, loop and warp".

No new command, no changed command metadata (no `argsSchema` / description edit), so the commands snapshot, the
canary figures and the A16 histogram are unchanged; `session.set_slot` keeps its reversibility class (journal
checkpoint on the `<session>` block). No project-format change: the fields and their attributes are Q050-013's.
Nothing on the audio thread changed (the GUI reads `session.get_state` on the UI thread; rendering is Q050-013's).

## Known limits
- The form is the shared schema-built `session.set_slot` form: it also lists the cell's other `set_slot` fields
  (type, pattern, name, mode, ...) blank; a blank field is not sent, so it changes nothing. Its labels come from the
  field names ("Transpose", "Detune", "Loop start", "Warp (BPM)"); the units (semitones, cents, ticks) are in the
  manual, not on the form - adding them would change `session.set_slot`'s schema.
- RAM mode is editable and saved but still changes nothing in playback (unchanged from Q050-013).
- The On/Off submenus do not mark the current value; the cell's badge shows whether it is warped.
- No inspector panel for launcher cells exists; the controls are on the cell's context menu only.
