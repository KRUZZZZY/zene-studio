# Q050-106 - Split stereo files and convert clips to mono

## Unit
P1, M (L05). A stereo sample clip's two channels can be written as two mono WAV files, and a sample clip's whole source can be destructively converted to mono with one undo. Both operations are reachable from the Sample Editor and the clip's Process menu, and both go through the control registry.

## Built
- `sample.split_stereo {clip, left_path, right_path}` (`src/core/ControlCommandsSampleStereo.cpp`, new): writes the full source's left channel to `left_path` and its right channel to `right_path` as mono float32 WAV, sample for sample, at the source rate and frame count. No resampling, trimming or mixing. Both destinations are written through `QSaveFile` and committed only after both temporary files are complete. The clip is unchanged; the command is `not_mutating`.
- `sample.edit_range` op `mono` (`src/core/ControlCommandsSampleRange.cpp`): the documented downmix, every frame becomes `(L + R) / 2` on both playback sides (`SampleFrame::average`). It converts the WHOLE source (a partial range is refused), keeps the rate, frame count, clip window and playback settings, and reports `channels: 1` / `layout: "mono"`. An agent needs only `{clip, op: "mono"}`: absent `from`/`to` default to the whole source (every range op still requires both bounds). One Clip checkpoint makes one `control.undo` restore the exact stereo samples and the stereo layout.
- `SampleBuffer` records the source layout (`channels()`, default 2) and `SampleClip` saves it as an additive `channels="1"` attribute only for a mono source; an older project has no attribute and loads as stereo exactly as before. The other sample bakers preserve the layout they found.
- Agent read-back: `arrangement.get_state`'s clip entries, `window.sample_editor`'s reply and `sample.edit_range`'s result report `channels` and `layout`. `clip.add`/`clip.delete`/`roll.get_state` schemas declare the two new nullable fields.
- GUI: the Sample Editor has `To Mono` (whole source) and `Split Stereo...` (a two-destination dialog) buttons; the clip's Process menu has `Convert to Mono` and `Split Stereo to Two Mono Files...`. All four run the same registered commands through `runCommand`/`ControlRegistry`.

## Commands and reversibility
- New: `sample.split_stereo` - `not_mutating` (two output files, no session change).
- Changed: `sample.edit_range` - still `true_inverse`; op `mono` is a whole-source bake with a Clip checkpoint.
- Surface: 850 ids / 76 groups after integration on `050/m0-train-16` (README canary updated; snapshot regenerated from a live instance). A16 histogram in `docs/RELEASE-NOTES-v0.3.0-alpha.md`: `rows=859 true_inverse=425 snapshot=42 irreversible=24 not_mutating=368`.

## Format
- `SampleClip` writes `channels="1"` beside `data`/`sample_rate` only for a mono downmix. Stereo clips and every older project write nothing, so existing files are byte-identical in this respect and load as stereo.
- No other project-format change.

## Known limits
- The two destinations are compared after resolving symlinks through their existing parent directories (a missing suffix is kept as written), so a symlinked directory cannot make both channels land in one file. Case-insensitive platforms also compare case-insensitively. Tests: `ControlSampleStereoTest::splitRejectsDestinationsAliasedThroughASymlinkedDirectory` (POSIX only) and `...splitRejectsCaseAliasedDestinationsOnCaseInsensitivePlatforms`.
- `sample.split_stereo` writes WAV only (float32) and refuses an already-mono clip. It exports the whole source, not the clip's window.
- op `mono` converts the whole source only; a partial range is refused rather than silently leaving part of the source stereo. `from`/`to` are optional for `mono` (they default to the whole source); other ops still require them. It does not resample or change the clip's window, timing or gain.
- File export is not undoable (it is not project state); the source clip is left untouched.
- The split destinations use the in-app two-field dialog rather than two native file pickers; both are ordinary typed paths.
