# Q050-048 - bound browser feature analysis to the analysis window

Unit: browser feature analysis of seekable audio keeps the decoded window to `BrowserFeatures::FeatureSeconds` (20 s) while
still reporting the full-file duration. Inputs without a usable length and DrumSynth files have the exceptions listed below.

## Built
- `SampleDecoder::decodeLimited(path, maxSeconds)` (include/SampleDecoder.h, src/core/SampleDecoder.cpp:202 onward, entry point :354):
  tries libsndfile, then Ogg Vorbis, then DrumSynth, as decode() does. For libsndfile and Ogg Vorbis it allocates and decodes
  only the leading window and returns the file's full length in frames (`BoundedResult::totalFrames`).
  - libsndfile: length from the header (`sfInfo.frames`). If the header carries none (frames 0 or unknown, e.g. a streamed WAV),
    the rest is counted by reading through a 64K-frame scratch chunk, so memory stays bounded and the duration is still true.
  - Ogg Vorbis: `ov_pcm_total` (last page granule position); only the window is read.
  - DrumSynth: synthesizes the complete output before cutting to the window. Its buffer and synthesis time can still grow with
    the DrumSynth envelope duration; this decoder is not bounded by `FeatureSeconds`.
- `BrowserFeatures::analyse` (src/core/BrowserFeatures.cpp:123) uses it; duration = totalFrames / rate.
- decode() and all existing callers (clips, preview, peaks) are unchanged.
- `SampleDecoder` has `LMMS_TESTING`-only full/limited call counters so the integration test can identify which decoder API
  `analyse()` actually invokes without adding a product-build metric.

## Known limits
- OGG/FLAC lengths are as the container states them; a Vorbis stream without a seekable length is refused by the bounded path and falls to the DrumSynth decoder (which refuses too), same as decode() would effectively.
- The no-length libsndfile fallback reads the remaining audio through a fixed 64K-frame scratch buffer to count duration, so memory stays bounded but I/O still covers the full file. `sfInfo.frames == 0` was not reproducible here; libsndfile derived length for the streamed-WAV case tested.
- DrumSynth synthesizes the complete output before truncation. Peak memory and synthesis time can scale with the full DrumSynth envelope duration; the browser's 20-second window does not bound this decoder.
