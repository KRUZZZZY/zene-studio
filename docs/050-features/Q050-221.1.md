# Q050-221.1 - Seeded melodic pattern tools, stage 1/3: seeded scale-aware melodic contours (P2, feature, L07)

**Unit.** Generate editable melodic contours reproducibly within the active scale, through the GUI and the agent
command surface. Members: R-editing-77, R-instruments-65. Stages 2 (persistent Euclidean settings) and 3 (a variation
page with MIDI control) are later units; nothing here stores page state they would have to undo.

**What was there (base `2a7fd9f9c`).** `note.generate` wrote a Euclidean or random rhythm on ONE key
(`src/core/ControlCommandsNoteTools.cpp`, `generate`); `note.transpose_in_key` moved notes by scale degrees; the
project seed (`note.random_seed_set`, `Song::midiSeed`) drove only velocity/timing jitter. Nothing generated pitches.

## What was built

| Piece | Where |
| --- | --- |
| `note.generate_melody {clip, contour?, target?, scope?, seed?, count?, step?, length?, start?, low?, high?, spread?, velocity?}` - a melodic line whose every key is a key of the active root and scale (`scaleContext()`, so custom scales from `scale.define` too) within `low`..`high` (48..72 by default). `contour` walk (a random walk, steps of 1..`spread` degrees, never standing still, turned back at the range edges), rise, fall, arch, valley (the shape over the scale's keys, moved by a seeded jitter of up to `spread` degrees; `spread` 0 = the bare shape). `target` new (default) writes `count` notes `step` ticks apart from `start`; existing re-pitches the notes in `scope` in time order and keeps their rhythm (so a `note.generate` rhythm can be given a line). ## Known limits

- The active scale is the session's (`scale.set`), as for `note.transpose_in_key`; with none set the call is refused.
- Pitch only: velocities and lengths are the arguments' (new) or the notes' own (existing). Rhythm generation stays
  `note.generate`; its saved settings are stage 2.
- Notes that start together (a chord) are re-pitched one after another, low to high, as steps of the line.
- A seed's line is fixed by this file's draw order; changing the algorithm later changes the lines old seeds give
  (`aSeedsLineIsPinned` will say so).
