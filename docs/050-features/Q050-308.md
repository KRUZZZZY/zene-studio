# Q050-308 Correct MIDI Clock menu documentation

**Unit.** R-workflow-117 (`L09`), docs, size S, P2: "MIDI clock input selection is socket-only". The
pain point was true of the 0.3.0 engine-only release and stopped being true twice - `Edit > MIDI Clock >
Clock Source` picks the follower's input (`src/gui/MidiClockMenu.cpp`, Q050-026), and `Project tools >
Sync > Follow MIDI Clock...` opens the `clock.slave_set` form whose fields include `source_port` and the
integer `drift_bound_ms` (`src/gui/LibraryCommandMenus.cpp`). `docs/KNOWN-LIMITATIONS.md` still said
"Choosing the port and the drift bound is still socket-only" (the queue's `:918` pointer is stale in this
checkout; the sentence had moved to `:1020`) and kept an older bullet titled "MIDI clock is the engine and
the socket, and there is no interface for it", so a reader could not tell that both values are settable
from the menus.

## Known limits

- The two historical records keep their measurements and are marked, not rewritten:
  `docs/RELEASE-NOTES-v0.3.0-alpha.md` (the 0.3.0-alpha "UI absence" bullet) and the 2026-09-13
  KNOWN-LIMITATIONS paragraph now titled "engine half". The gate accepts these only because they carry a
  dated marker, and rejects a bare "still socket-only" sentence outright (the word "still" asserts the
  present, so no marker can excuse it).
- Dated lane records are outside the sweep: `docs/bunny-fixes-2026-10-05/`, `docs/qwen-fixes-2026-10/`
  (review reports), `docs/050-features/` (unit records, which necessarily QUOTE the sentence they
  removed - this record cites three of them) and every `*-logs/` directory. They record what was true
  when they were written; the current-facing pages (KNOWN-LIMITATIONS.md, the manual,
  FEATURE-LIST-0.3.0.md, the release notes) stay in the sweep.
- The gate cannot prove a musician's MIDI device exists. It proves the documented GUI routes are the
  real ones (`MidiClockMenu.cpp`, `LibraryCommandMenus.cpp`), that the form drives the same registered
  command an agent does, and that the documented bound is the schema's bound.
- `LibraryMenusTest` runs headless, so it proves the Sync entry opens `clock.slave_set`'s form and that a
  form Run reaches the engine; it does not enumerate a physical port list (none exists without a backend,
  which is why the source value is asserted through `clock.get_state`).
