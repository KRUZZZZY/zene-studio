# Q050-029 - Reject invalid remote knob indices

Type: fix (P0, size S). Member: R-workflow-12. Area: L15.

## What was built
- `src/core/RemoteControls.cpp`: `RemoteControls::applyKnob` now validates `knob` (0..`Knobs`-1) before computing the paged model index `pageWithin(m_page, models) * Knobs + knob`; the index is accumulated in `qlonglong` and the `models.at` access uses the checked integer after both bounds checks. `sendPage()` and `state()` use the same wide integer index arithmetic. Malformed (negative, out-of-range, extreme) knob requests therefore return `false` without any model access or integer overflow.
