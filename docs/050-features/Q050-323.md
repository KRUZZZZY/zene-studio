# Q050-323 — Task-indexed quick-start and area reference

## What changed

The manual now has a **Quick start** section with six searchable task guides: make a first beat; arrange clips; edit
notes; add an instrument or effect; record and comp takes; mix, export and hand off. Each names current controls and
menu paths, links its area reference, lists the registry commands an agent uses, and links the installed tour where
one exists (`first-beat`, `recording`, `mixing`). The eleven existing area references remain the single `HelpTasks`
map.
