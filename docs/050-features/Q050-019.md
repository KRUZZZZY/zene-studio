# Q050-019 - Chord progression panel (P0, M, L07)

Branch `feat/050-Q050-019-oc`, based on train 5 (`050/m0-train-5`, `de5a85a96`).

## The unit

Goal: browse named progressions, see suggestions for the current scale, preview them, and write a
chosen progression from the interface.

The command existed (`chord.progression_generate` / `chord.progression_list`) and was reachable only
from the clip menu's raw command form and from the socket; `B-ED-119` and `R-editing-6` recorded
that the promised user-facing panel was absent. This lane adds the panel, the read that feeds it,
and the two proofs that the interface and the headless workflow are the same command path.

## What was built

- `src/core/ControlCommandsChord.cpp:121` - `progressionSuggestions(scale, root, octave)`: the
  catalogue evaluated against a key, each entry's own chords named by the same vocabulary the
  generator writes with. `chordProgressionList` (`:218`) gained optional `scale`/`root`/`octave`
  arguments and reports `suggestions[]` (plus `suggest_scale`/`suggest_root`/`suggest_octave`) when
  a scale is named. No new command id: this is the same read-only catalogue verb, one argument
  wider, so no snapshot id, canary or histogram class changes for it.
- `include/ChordProgressionPanel.h`, `src/gui/ChordProgressionPanel.cpp` - `gui::ChordProgressionPanel`,
  a `QDialog` that is a view over two registered commands and nothing else: the scale/key/octave
  selectors drive `chord.progression_list {scale, root, octave}` into the suggestion table
  (`showSuggestions`, `:202`), and the Write button (`controlCommand` property
  `chord.progression_generate`) writes the selected progression into the shell's selected MIDI clip
  (`writeTo`, `:300`; `writeSelected`, `:313`).
- `src/gui/ControlCommandsShell.cpp:313` - `registerProgressionPanel`: the new `window.progression`
  command (opens the panel non-modally, like `window.tempo_map` / `window.modulators`).
- `src/gui/MainWindow.cpp:404` - the Edit menu's `Progression...` action dispatches it.
- `src/gui/shell/ShellToolsMenu.cpp:78` - the footer Tools menu lists it too.
- `src/core/ControlReversibilityTableShell.cpp:112` - the A16 row: `NotMutating` (interface state;
  the Write button runs `chord.progression_generate`, which has its own row).

## Format changes

None. The panel writes notes into a MIDI clip through the existing command and touches no project
format byte; `chord.progression_list` is a read.

## Known limits

The preview is the chord names the catalogue spells in the key, not an audition - nothing is played
before the write. The target is the shell's selected MIDI clip (there is no clip picker in the
panel), so a selection is required. The panel exposes scale, key, octave, progression and the
clip's own `replace` default; `pattern`, `velocity`, `seed` and `variation` are not controls here
(they keep `chord.progression_generate`'s defaults). The panel does not edit the chord track.
