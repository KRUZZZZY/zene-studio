# Q050-202 — Migration and accessibility keymap setup

## What changed

- Four shipped maps (`shortcutPresets()`): Accessibility, Ableton Live, FL Studio and Logic Pro. They map Zene menu
  actions by the registry command each action declares, so a menu rename cannot leave a stale override id.
- `shortcuts.preset_list` (NotMutating) lists them; `shortcuts.preset_apply` (TrueInverse) applies one, first writing
  the current set to a timestamped `shortcuts-backup-*.json` in the workspace. The undo restores the previous
  overrides; the backup file deliberately survives the undo and can be restored with `shortcuts.import`.
- The Keyboard Shortcuts page has a **Presets...** menu that invokes the same commands.
- The manual's Access section names NVDA, VoiceOver and Orca and links `docs/ACCESSIBILITY-TEST-MATRIX.md`, which
  honestly marks every row not run where it was not run.

| Criterion | Test and what it proves | Result |
|---|---|---|
| Accessibility and source-DAW presets apply to real menu actions through the GUI and agent surface. | `ShortcutsCommandsTest::theShippedMapsApplyRoundTripAndLeaveABackup` applies all four and reads back `transport.record`; `ShortcutsPageTest::thePageAppliesAShippedKeyboardMap` triggers the page's menu action. | `0` |
| Import preserves a backup and each preset exports/re-imports. | Same command test checks the backup file exists and restores it, then exports/resets/imports each preset and compares the active binding. | `0` |
| In-app guidance names the supported readers and links the tested matrix. | `ShortcutsPageTest::theManualNamesTheReadersAndLinksTheTestedWorkflowMatrix` reads the manual and matrix. | `0` |

Commands added: `shortcuts.preset_list` (not_mutating), `shortcuts.preset_apply` (true_inverse). No project format change.
