# Q050-099 — Keyboard editing for waveform and MPE lanes

## What changed

- The sample waveform takes keyboard focus and exposes an accessible Canvas value. Left/Right move its cursor,
  Shift+Left/Right extend the selection, Home/End go to the ends, Ctrl+Plus/Minus zoom, Ctrl+0 shows all and Ctrl+A
  selects all. The existing range-operation buttons then apply `sample.edit_range`, so an edit is still one undo step.
- `note.edit` gained the MPE `pitch` field (-4800..4800 cents) and already accepted `timbre` and `pressure`. The
  expression lane now writes every selected note in one validated `note.edit` batch for all lanes, including the MPE
  lanes; its readout names the lane, value and selected-note count.
- The stale KNOWN-LIMITATIONS wording for the waveform and MPE keys is corrected. Cursor movement, range
selection and zoom are view state, not project edits: like every other canvas cursor they do not enter the undo
history. "Each operation is undoable" is met for the operation that changes the project - the applied range edit -
and one `control.undo` restores the audio.
