# Q050-164 - Expose per-sample modulation in the panel

Unit: P1, size S, area L06, type feature. Branch `feat/050-Q050-164-oc`, base `050/m0-train-24`.

Goal: turn per-sample evaluation on or off for a bound modulation route from the Modulators panel.

## New command

`modulator.per_sample_set {modulator, target, per_sample}`: `true_inverse`, mutating. The value reads back as the target's
`per_sample` in `modulator.get_state`. A non-boolean is refused (`InvalidArgs`), a missing route is `NotFound`.

## Format

No change. The existing `persample` attribute is written only when on, and an absent one still means off, so old projects
load and render as before.

## Realtime

The command and the checkbox run on the control thread through `editModulationLayer`, the same publication path as
`modulator.depth_set`. No audio-thread code changed; the existing allocation-free path reads the flag.

## Known limits

- A route the instrument takes per note (per-voice modulation) is evaluated per voice, so the switch does not change it.
- An open panel does not follow an undo or an agent's edit until it refreshes, the same as its depth column.
- The evaluation proof reads the control-side runtime; the render-side copy goes through the unchanged publisher.
- The panel still shows depth read-only.
