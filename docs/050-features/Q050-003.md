multi-out and instrument latency compensation are absent; the merged host has all three

`docs/KNOWN-LIMITATIONS.md` instrument-hosting bullet, and retains the third-party-untested

## Known limits (stated in the docs as shipped)

- The in-tree VST3 fixture has a single output bus, so the routing of a real multi-output
  VST3 plug-in is unproven (`plugin.output_*` is measured against `buses_test_instrument`).
- The editor proof is one offscreen contract test; no third-party plug-in's editor has been
  opened on a real display (X11-embedded only; float-only plug-ins refused).
- The plug-in's own preset (program) lists are not read; there is no out-of-process hosting.
- VST3/CLAP effect multi-out is not claimed: effect hosts flatten active output buses into
  the chain (`plugins/Vst3Effect/Vst3BusMap.h:62`); `plugin.output_*` addresses instruments.
