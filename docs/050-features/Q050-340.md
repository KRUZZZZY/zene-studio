# Q050-340 - Input meters for capture channels and armed tracks

Unit: P2, M, area L08 (B-MX-134). Goal: users can see live level meters for individual capture channels and the inputs
feeding record-armed tracks. Batch: `feat/050-Q050-088-oc`.

## What was built

- **Audio thread** (`src/core/InputMeter.cpp`, `src/core/AudioEngine.cpp`): each period, every capture channel's peak
  from the raw wide capture (else the stereo bus as channels 0/1) is raised into fixed relaxed atomics, one set per
  reader (interface, agent) - 2 x 128, no allocation, no lock; each reader takes and resets only its own.
- **Shared readings** (`include/InputReadings.h`): channel peaks plus every record-armed route's selected input and
  its track (route n = the song's n-th track); silence when the selected channel delivered nothing; independent of
  monitoring.
- **Agent**: `meter.inputs` (`not_mutating`) - `channel_count`, `channels` (peak, peak_db, clipped), `armed` (route,
  track, track_name, input_channel, peak). `window.input_meters` (`not_mutating`) opens the window and answers what it
  shows.
- **GUI**: Mixer View > Input Meters... - a labelled bar per capture channel ("In 1".."In N") and per armed track
  ("<track> - In k"), -60..0 dB, mixer fall-off; an accessible description lists the levels.

## Commands and format

- New: `meter.inputs`, `window.input_meters` (both `not_mutating`). No project format change (meters are transient).

## Known limits

- PortAudio and SDL deliver only the stereo bus, so they show two inputs.
- One interface reader and one agent reader: two windows (or two agents) would share their reader's maxima.
