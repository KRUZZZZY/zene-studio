# Q050-088 - Console channel-strip controls and glue compression

Unit: P1, L, area L08 (R-mixing-17, R-mixing-32). Goal: users can optionally reach trim, polarity, three-band EQ,
Console drive and a glue compressor directly in the mixer's Console workflow. Batch: built with Q050-108 /
Q050-262 / Q050-339 / Q050-340 on `feat/050-Q050-088-oc`.

## What was built

- **The glue compressor** (`plugins/Console/Console.{h,cpp}`): an optional stage after the Console's tone, before its
  output - stereo-linked feed-forward, 10 ms attack, 100 ms release, hard knee; parameters `glue` (off by default),
  `gluethreshold` (-40..0 dB, -10), `glueratio` (1..20, 4), `gluemakeup` (0..24 dB, 0), registered as ParameterControls
  keys so they save, load and undo with the device. Off, the stage is skipped and the arithmetic is the old one
  bit for bit (`(shaped * output) * wet`); an older Console state with no `glue*` keys loads with the glue off
  (`AutomatableModel::loadSettings` resets an absent key). The device reports its reduction (`gainReductionDb`), so
  the strip's GR meter shows it.
- **One shared model of the section** (`include/ConsoleStrip.h`, `src/core/ConsoleStrip.cpp`): the channel's trim,
  polarity L/R, EQ (low, mid, mid frequency, high - the same `MixerChannel` models `mixer.set_strip` and
  `mixer.channel_eq` write) and its first Console's drive and glue; read, apply, JSON, and a validating merge that
  writes nothing unless every field is valid.
- **The command** `mixer.console_strip` (`src/core/ControlCommandsConsoleStrip.cpp`): sets and reads one channel's
  section; a Console field on a channel without a Console is refused (`refused`, naming `mixer.console_apply`); a
  bad value is `invalid_args`; a refusal changes nothing and records no undo step; a change is ONE undo step
  (`true_inverse`, coalescing on `channel`, so a knob drag is one step). `mixer.console_apply` keeps its global
  behaviour.
- **The view option** `window.mixer_view` `show_console` (off by default, kept in `ui/mixerview`, hidden in the
  routing view and the compact density) and the menu choice Mixer View > Show Console Section.
- **The strip section** (`src/gui/ConsoleStripSection.cpp`): small knobs for trim, EQ low/mid/high/mid frequency,
  Console drive, glue threshold/ratio/makeup and switches for polarity L/R and glue; every edit runs
  `mixer.console_strip` on that channel; the Console's controls are disabled (and "No Console" shown) without one.
  Showing the section adds no processing.
- `tests/CMakeLists.txt`: `DeviceDspTest` (and the new tests) now `add_dependencies(... console)`, so a targeted
  build no longer skips the Console cases (the review's root-cause item).

## Commands and format

- New: `mixer.console_strip` (`true_inverse`, coalesces on `channel`). Changed: `window.mixer_view` gains `show_console`.
- Format: the Console device saves four more parameters (`glue`, `gluethreshold`, `glueratio`, `gluemakeup`); absent
  keys load as the defaults (glue off). The strip's own values keep their existing attributes.

## Known limits

- The section edits the FIRST Console on a channel's chain; a channel with two Consoles shows the first.
- The glue's attack and release are fixed (a bus compressor's 10 / 100 ms); no knee, sidechain or auto-release.
- The strip's knobs are small and unlabelled (tooltip, hint and accessible name carry the label).
