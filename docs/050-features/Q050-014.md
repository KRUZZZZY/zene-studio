# Q050-014 Document supported plug-in formats and caveats

Unit: P0, size S, area L10 devices/instruments/effects/plug-in hosting. Branch
`feat/050-Q050-014-oc`, base `de5a85a96` (train 5).

Goal: users can distinguish native format **loading** from unverified bridge and Kontakt-library
**compatibility**.

The unit is a documentation-truth fix (members `R-instruments-11`, `R-instruments-26`, `R-ui-19`):
two current-facing docs blurred what this build *loads* with what has been *tested*, and both still
carried a stale claim that the plugin scan cache and its per-file records were socket-only / "not a
GUI" even after `CommandLists::pluginModules()` ("Plug-in Modules") shipped the interface.

  Manager" wording is pre-existing and out of scope here.
