# Q050-054.2 - Record and comp MIDI takes on instrument tracks, stage 2/2: MIDI comp UI (P1, feature, L03)

## Before

Take lanes were offered only on sample tracks, and no MIDI notes were drawn in the comp strip.

## What was built

| Piece | Where |
| --- | --- |
| Take lanes are available on instrument tracks through the track menu | `src/gui/tracks/TrackOperationsWidget.cpp` |
| Each MIDI take's notes are drawn in its lane in the comp strip | `src/gui/CompSwipeStrip.cpp`, `include/CompSwipeStrip.h` |

## New and changed commands

None. The workflow uses the existing registered `comp.get_state` (`not_mutating`), `comp.assign` (`true_inverse`) and `comp.select` (`true_inverse`). Capture uses the stage-1 `record.midi_capture_commit` (`true_inverse`).

## Acceptance

| Criterion | Test | What it proves | Exit code | RED exit code |
| --- | --- | --- | --- | --- |
| A GUI selection gates MIDI playback by note start and survives save/load | `MidiCompLaneGuiTest::aMidiLaneRegionSelectedInTheStripGatesPlaybackAndSurvivesSaveLoad`, `theStripDrawsAMidiTakesNotes` | Real menu and strip drag, note drawing, boundary playback and save/reopen | 0 | 8 with product hunks reversed; 8 with note drawing removed |
| Workflow actions have registered schemas and undo coverage; comp edits undo and redo | `MidiCompLaneGuiTest`, `TakeLaneCompTest`, `TakeLaneCompPlaybackTest`, `ReversibilityContractTest`, `ControlCommandsSnapshot`; stage-1 `MidiTakeRecordTest` for capture | One undo step per drag, undo/redo and invalid selection refusal; existing command schemas and classes; capture's stage-1 inverse | 0 for GUI, neighbours and contract suites; stage-1 capture proof | 8 for GUI with product hunks reversed |

## Realtime

The diff is GUI-only: the track menu and strip painting run on the GUI thread. Playback gating remains the unchanged stage-1 `InstrumentTrack::takePlays` / `compPlays` code.

## Format

None. Existing lane and takegroup clip attributes and `<z:lanes>` hold the state; old projects are unchanged.

## Known limits

- The strip sketches notes; it is not a piano roll.
- Assign clips to lanes through `comp.assign` or drag.
- Build evidence used `ZENE_BUILD_GUARDED=1` to bypass the build guard and disabled ccache (`CCACHE_DISABLE=1`): the default lock, temporary and log directories were not writable in the sandbox. The build kept `-j4` and logged to `/tmp/q0542-logs`.
