# Q050-145 - Document Zene's current free and activation model

Type: docs (P1, size S). Member: R-hosting-18. Area: L14 (help, onboarding, accessibility).

## Goal

Know whether the current Zene build has paid tiers or requires activation, and where policy changes will be announced.

## What was built

- `README.md:213` (`## License and attribution`) through `README.md:218` (`## Free and activation model (current build)`) now states the verified current state and the announcement channel.
  - The current build distributed from this repository is GPL-2.0-or-later only, with no paid tier, registration or activation: no separate free/pro/enterprise edition, no account or licence-key step, and no online or periodic validation anywhere in the application or its build.
  - Verified against `LICENSE.txt:21-36` (the clause allowing copies to be distributed "gratis or for a fee" while keeping all rights) and against a source search of `src/`, `include/` and `plugins/` (excluding the vendored third-party libraries under them) for activation, licence-key, subscription, registration, premium and serial-number handling. Every surviving match is an unrelated technical use (port/event subscription, MIDI port subscription, plugin host/driver "activation" of a module); none is product licensing, from `logs/search-4.log`.
  - No future pricing or availability policy is promised. If one is ever adopted, it will be announced in the release notes of a tagged release published through the GitHub Releases page for `KRUZZZZY/zene-studio` (the channel through which releases are published; see `docs/RELEASING.md`), not silently, and reported through `--version`.
