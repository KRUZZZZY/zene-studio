## Goal

Know whether the current Zene build has paid tiers or requires activation, and where policy
changes will be announced.

## What was built

- `README.md:218` (`## Free and activation model (current build)`), rewritten in round 2:
  - **The license paragraph** (`README.md:220-224`): the project's license is
    GPL-2.0-or-later (`LICENSE.txt`); the GPL governs freedom, not price, explicitly permits
    distributing copies "gratis or for a fee" (`LICENSE.txt:34`), and therefore settles
    nothing about whether any build, present or future, is sold or has tiers. The charging
    clause is cited as a licence fact, explicitly NOT as verification of the no-tier state.
  - **The current-facts paragraph** (`README.md:226-246`): the no-paid-tier /
    no-registration / no-activation statement is grounded in the repository itself, not in
    the license, in two verifiable facts:
    - the search of the product-owned C/C++ sources (`src/`, `include/`, `plugins/`, with the
      same vendored exclusions as `tests/all-sources.txt` - `src/3rdparty/`, the
      `calf/cmt/swh/tap`, carla, game-music-emu, portsmf, adplug, resid, exprtk, zynaddsubfx
      submodules, `plugins/NeuralAmp/{rtneural,nam,tests}`, `plugins/RnnoiseDenoiser/rnnoise`)
      for licence-key, activation-code, serial-number, product-registration, purchase,
      premium, free-trial and paid-tier handling returns no product-licensing match; the only
      remaining broader-word matches are unrelated technical uses, now stated with their
      actual scope: two comments measuring this product against a *competitor's* pro tier
      (`include/AudioInputPath.h:84`, `include/MultiTrackRecorder.h:86`), MIDI port and event
      subscription, and Qt signal / plugin-instance "activation";
    - the build and release process documented in the repository names no account, licence
      key, purchase or price anywhere; `docs/RELEASING.md` records that the release page is
      the only distribution point.
  - **The announcement paragraph** (`README.md:248-252`): no future pricing, tiering or
    licensing policy is promised or implied ("none is decided"); if a future release changes
    these terms, the change is announced in that release's notes - authored as
    `docs/RELEASE-NOTES-<version>.md` and published in full on the GitHub Releases page for
    `KRUZZZZY/zene-studio` (the only release channel the project has, per `docs/RELEASING.md`).
    The `--version` policy-reporting promise of round 1 is removed entirely; `--version`
    (src/core/main.cpp printVersion) prints build metadata and a GPL notice and makes no
    policy claim.
