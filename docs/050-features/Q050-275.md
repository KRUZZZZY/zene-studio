# Q050-275 - Named track versions as comp sources

Goal: a named track version can be used as a take-lane comp source. Track > Versions > Use as Comp
Lane (agent: `track.version_to_lane`) turns the version's clips into a new take lane, so the user
can comp from a named playlist with the existing comp tools.

## What was built

- Track versions are reused as the named playlists: each version stores a track's clips, and
  switching versions changes which clips the track plays. No new storage was added for them.
- `track.version_to_lane` (`track`, `name`) adds a take lane named `name` that holds copies of the
  stored version's clips as they are at that moment. The command is `true_inverse` and is one undo
  step; the version itself is not changed.
- Design choice: a comp source is a copy taken at the moment of use, and the copy is kept in every
  stored version. Later edits to the version do not follow into the lane, so a comp never changes
  when the version is edited.
- A track with no lanes first gets a base lane for its own clips, so the new lane has something to
  comp against. Switching versions keeps the lane and its takes.
- Versions > Use as Comp Lane in the GUI calls the same command, and a GUI test triggers it.

Format changes: none new. Lane copies are ordinary clips with the existing `lane` attribute. They
are stored inside the existing `<track-versions>` CDATA and the existing take-lane section. Projects
without versions or lanes save exactly as before.

## Known limits

- The lane is a copy: it does not follow later edits to the version.
- Removing the version keeps the lane; the lane is not deleted with its source.
- The base lane takes the active version's name, or `Main` when there is none.
