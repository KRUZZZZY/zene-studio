# Q050-255 - Edit folder summary clip spans

Unit: M, P2, L04. Goal: select, resize, split and keyboard-edit folder summary clips as group edits over their child tracks.
Built in one batch with Q050-219, which shares `include/ClipGroupEdits.h`.

## What was built

- **One clip set per edit.** `track.folder_span_*` take `spans` (or, without it, the selected summary clips) and `clips` (ordinary clips), and resolve them to one set, so a clip reached twice changes once. Every holding track is checkpointed as one undo step. Nothing is written until the whole edit has been planned and accepted.
- **Resize** (`arrangement::planSpanResize`). Lengthening takes the clips already at that edge out to the new edge. Shortening cuts each clip crossing the new edge and removes those wholly past it. A head trim moves the start offset with the start, so the content stays in place on the timeline (the `clip.trim` rule). An edge cannot pass a neighbouring summary clip.
- **Split.** Cuts every crossing clip, nested tracks too. Touching pieces still draw as one summary clip, because spans are derived.
- **Selection** (`FolderSpanSelection`, interface state). Each entry follows one child clip, and after an undo rebuilt the clips it finds the span at the tick it last saw.
- **GUI** (`FolderSummaryLane`). Click selects, Shift or Ctrl+click adds or removes, and a ring marks selected spans. Dragging an edge shows the resize cursor and a dashed preview. Menu: Select, Split here. Dragging a selected span moves the whole selection. A plain click on an ordinary clip clears the span selection; Ctrl+click keeps both.
- **Keys** (`ArrangerClipKeys`). Ctrl+Alt+G selects (Shift adds). With a span selected: Ctrl+Alt+Left/Right moves the end edge (Shift the start edge), Ctrl+Alt+K splits at the play position, Ctrl+Alt+Page Up/Down moves, Delete deletes, Escape deselects. With no span selected these keys behave as before.

## Commands

| Command | Class | What it does |
| --- | --- | --- |
| `track.folder_spans` | not_mutating | Reads a folder's summary clips and the selection |
| `track.folder_span_select` | not_mutating | Selects, adds, removes or clears; interface state |
| `track.folder_span_resize` | true_inverse | `edge`, `delta` over the targets |
| `track.folder_span_split` | true_inverse | `at` over the targets |
| `track.folder_span_move` | true_inverse | `delta` over the targets |
| `track.folder_span_delete` | true_inverse | Deletes the targets' clips |

Format: no change. Summary clips stay derived; child clips save as they always did. Realtime: everything runs on the UI thread, nothing on the audio path.

## Known limits

- Lengthening moves only the clips already at that edge, not every clip in the span.
- `track.folder_span_delete` does not ripple; the single summary clip's menu delete still follows the arranger's ripple mode.
- A group split takes no zero-crossing snap, so all pieces cut at the same tick.
- A locked clip among the targets refuses the whole edit.
- Lengthening a sample clip past its audio leaves silence, as `clip.resize` does.
