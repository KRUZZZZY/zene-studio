# Q050-481.3 - Open older VST2 projects as Carla devices

## What was built

- The core converter in `include/LegacyVst2Conversion.h` and `src/core/LegacyVst2Conversion.cpp` maps `param<N>` to `PARAM_KNOB_<N>` while retaining model ids, so automation and controller links survive. It resolves the key from Carla's VST2 listing by canonical path, or else by file.
- `InstrumentTrack::loadConvertedInstrument` and EffectChain's `loadConvertedEffect` hook conversion into loading, falling back to the legacy reader on the original XML.
- `plugins/CarlaBase/CarlaVst2Legacy` restores program, then chunk, or else the `numparams` dump, using `carla_set_program`, `carla_set_chunk_data` and `carla_set_parameter_value`. Only models with saved settings are reloaded.
- The VeSTige path fix preserves the saved plug-in path when the file is missing.

## Failure and boundary paths

`aMissingBinaryKeepsTheLegacyDevice` covers a missing binary; `aBinaryCarlaCannotLoadFallsBackToTheLegacyReader` covers a binary Carla cannot load. The invalid dump entry `param2="9:Bogus:x"` and the unit cases cover malformed data and conversion boundaries.

## Commands, undo and format

There is no new or changed command; `project.open` keeps its snapshot class. The saved format is unchanged. The `<zene-legacy-vst2>` marker exists only in memory during load and is never saved.

## Realtime

Conversion and Carla calls run on the GUI thread with the VST2 worker paused; no audio-thread code changed. TSan was not run on this box, so this is reasoned, not measured.

## Portability

Linux native is verified. Wine-bridged (`.dll`) legacy conversion takes the same path but is untested here: there was no PE toolchain, so no Wine bridge was built. No Qt-6-only API is used.

## Environment notes

The worker sandbox could not write the run folder's logs or the build-pool lock. Logs are in `build/duet-logs`; builds ran with `ZENE_BUILD_GUARDED=1 -j4 CCACHE_DISABLE=1`.

## Known limits

Pins and channel settings are dropped; parameters beyond the rack's slots are ignored with a warning; `guivisible` is not carried. Conversion needs the `carlavst2` modules and a runtime. First-load discovery may run Carla's discovery tool once per binary. Presets (`.xpf`) convert through the same InstrumentTrack path.
