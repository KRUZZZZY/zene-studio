# Q050-262 - Surround-aware send panning

Unit: P2, M, area L08 (R-mixing-23). Goal: users can pan sends into surround channels with the destination's
speaker layout, divergence and LFE send settings. Batch: built beside Q050-088 / Q050-108 / Q050-339 / Q050-340
on `feat/050-Q050-088-oc`.

## Verdict: already in the tree - no product change

The scoping brief (gpt-6-luna, train 8) found both criteria implemented; this branch re-verified every pointer
against the code at its base and ran the proofs on a build of this branch:

- **The surround panner of a send's source, mapped to the destination's layout.** `src/core/MixerSurroundMix.cpp`
  takes the source channel's panner gains for the RECEIVER's speaker format and routes the send onto those
  speakers and the LFE (`panTakesSend` and `panSend`, `MixerSurroundMix.cpp:195-225`). The panner is the source
  channel's (channel-wide across its surround sends), which is what the queue item asked for ("the channel's
  surround pan").
- **Divergence and LFE on the agent surface.** `mixer.surround_pan` sets `x`, `y`, `lfe` and `spread` (the
  divergence-like control is called `spread`) and `mixer.surround_get` reads them back with every surround send's
  destination and format (`src/core/ControlCommandsMixerSurround.cpp:67-72, 93-115, 304-333`); both are in the
  reversibility table (`mixer.surround_pan` `true_inverse`, `mixer.surround_get` `not_mutating`,
  `src/core/ControlReversibilityTableMixing.cpp`).
- **The GUI.** The channel menu's Surround > Surround Panner shows the destination layout and has LFE and Spread
  controls (`src/gui/MixerHardwareMenu.cpp:116-127`, `src/gui/SurroundPanner.cpp:214-223, 249-282`).
- **Stereo sends keep their balance.** `mixer.send_pan` remains the stereo balance command and path
  (`src/core/ControlCommandsMixerListen.cpp:132-135`, `src/core/MixerSendPan.cpp:44-88`); nothing in this
  batch touches either (the batch's PDC change only adds a manual offset that is 0 by default).
- **Projects.** The panner is saved only when off its default; legacy projects load as stereo with the panner off
  (`src/core/MixerSurround.cpp:392-422`).

Because there is no product change, there is no new test whose revert could make it fail; the acceptance is
proven by the existing tests named below, run on this branch's build (exit codes in the table).

## Known limits

- The panner belongs to the source channel: every surround send of that channel takes the same position.
  Independent per-send panners are not built (additional scope, not this unit's acceptance).
- ADM translation and new speaker layouts are out of scope, as the brief states.
