## Notes

- **8e988406b, test damage (not fixed by this lane, needs owner decision).** The original test
  wrote `alpha` and `decoy` into the user's real preset folder with `overwrite:true` and then removed
  them. On 2026-10-05 23:36 both files were moved to the trash:
  `~/.local/share/Trash/files/alpha.xpf` and `decoy.xpf`, originally at
  `~/Documents/Zene Studio/presets/CLAP/`. Their trash copies are dated 23:35, so they are the
  test's own writes. Any user file that the overwrite replaced before that run is not recoverable
  from here. The fixed test writes only to a temporary directory; the real folder's mtime is
  unchanged across a green run.
- **87622d5ba, no failing-without-change test.** The restore closures used to mix a captured Song
  pointer with `Engine::getSong()`. Engine creates the Song once, so the two are the same for the
  life of the journal and no public path can tell them apart. The reversed product passes
  SessionCommandArgsTest, so the rework is a consistency change with no test that goes red.
  `Song::setModified(bool)` is private, so a clean-flag case cannot be written without a save.
- **873124875, changed expectation.** `contractRowsClassifyTheGroup` asserted that the first add to an
  empty inactive map advertises `tempo_map_remove`. That add also activates the map, and remove
  keeps the active flag, so the advertised command is the defect the review flagged. The assertion
  now asserts the checkpoint. This changes an expectation to match the contract; it does not weaken
  a check.
- **e39984ffb, untested branch.** The refusal for a place whose volume `QStorageInfo` cannot
  measure is implemented (`groupByVolume`) but not exercised: on this machine existing paths are
  always valid, so there is no way to reach it from a test.
- **354232bbf, helper.** `controlReplaceFileAtomically` (declared in `include/ControlProjectAssets.h`,
  defined in `src/core/ControlCommandsProjectLifecycle.cpp`) is the replacement step. The replacement
  test calls it directly, because the headless test process has no midiexport filter, so the export
  command cannot reach the replacement step.
- **Pre-existing failures, unchanged by this rework.** `InstrumentLayersCommandsTest::outputBusesAnswerTyped`
  (documented in batch-08.md) and `ReversibilityUndoTest::firstAutomationPointIsOneUndoableStep`
  (documented in batch-06.md, batch-17.md). Both fail on the unmodified branch; neither was run in
  the full suite.
- **Not run.** No full `ctest`, no `run-all-gates.sh`. Per the brief, only targeted tests ran; the
  related set ControlVerbInverseTest, ControlResultSchemaTest, ControlSurfaceReferenceTest,
  ControlRegistryTest, ReversibilityContractTest, ControlVcaEditGroupsTest, ControlVcaLockedEditsTest
  and UndoBoundsTest passed. ReversibilityUndoTest failed only on its pre-existing automation case.
- The InstrumentLayersCommandsTest shared track means `layerZoneRemoveAdvertisesAReplayableInverse`
  depends on earlier cases for `basePlays(65)` (an inactive layer system plays every key). It
  passes in the full binary and fails in isolation; this predates the rework and is left as is.
