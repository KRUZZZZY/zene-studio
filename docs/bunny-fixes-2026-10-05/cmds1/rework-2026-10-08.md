Notes:
- The join overflow test cannot fail on the pre-fix file. Two's-complement wrap gives the same final
  value, so ctest sees no difference. The defect is shown by a standalone UBSan check, kept in scratch
  (`scratchpad/agents/cmds1/ubsan/join_expr.cpp`, not in the repo):
  `g++ -std=c++17 -O0 -fsanitize=signed-integer-overflow -fno-sanitize-recover=all`. The old order
  aborts with "signed integer overflow: 2147483147 + 800 cannot be represented in type 'int'"; the new
  order exits 0 with the expected value. The ctest test pins the values at a non-zero origin.
- The exact-boundary write (start 0x0FFFFFFF, length 1) is a coverage check. The old writer also wrote four-byte
  deltas, so it passes before and after. The red for this commit comes from the message check.
- Negative note positions are now refused by the time-scale preflight (`fitsTick`). Not reachable in
  normal projects; it is a behaviour change and is stated here.
- Still open, unchanged: the join does not preflight other clips' end positions or the joined length
  (ClipArrange, pre-existing); the library save's redo ignores a refused write (pre-existing); the library
  save's redo re-renders the live clip (documented); the root-account SKIP for
  aSaveNeverReplacesAFileItCannotRead (a host that can read write-only files reports SKIP, not PASS).
