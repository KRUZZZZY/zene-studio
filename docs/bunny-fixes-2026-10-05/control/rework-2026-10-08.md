## Decisions and limits

- **Registry (4a01e6dd0).** A mutating call records its step unless an enclosing handler is mutating. A nested mutating
  call whose record is folded into an enclosing step is counted; if the enclosing call has no descriptor of its own, its
  record is `reversible: false` with a mechanism that says so. The nested descriptor is not composed into the outer
  record, so the outer's own descriptor is kept when it has one. Composing both is not implemented.
- **Inflate (49f0ee50e).** The `.mmpz` body is inflated with zlib and capped on produced bytes. zlib is linked only when
  `find_package(ZLIB)` succeeds (`ZENE_HAVE_ZLIB`, `src/CMakeLists.txt`, registered in `tests/upstream-modifications.txt`).
  Without it the reader falls back to `qUncompress`, where only the declared-size refusal applies. Windows and macOS
  builds were not run here, so the zlib link on those platforms is unverified.
- **Read bound (49f0ee50e).** Both bodies are read through `readBoundedBody` (cap+1 bytes). A file that grows during the
  read is covered by code, but no deterministic regression exists for the growth race itself.
- **Engine recovery.** `src/core/DataFile.cpp` (`decompressesAsRecoverableDocument`) has the same header-as-bound premise.
  It is inherited and outside this lane; not changed.
- **Numeric validation (d53d36aec).** The conversion-before-check hazard was already fixed at `58cf719ea` (not in the
  reviewed tip `701560e28`). This rework adds the negative-extreme, fractional and INT_MIN fixtures the review asked for.
- **Not run.** The full ctest suite was not run (other suites were running on the machine). Suites run at the final tree,
  all EXIT=0: ControlRegistryTest, RangeEditsTest, UndoHonestyTest, ReversibilityContractTest, ProvenanceSectionTest,
  ControlResultSchemaTest, ProjectToolsTest, ControlNoteScaleVerbsTest, ControlProjectArchiveTest.
- **Other review items.** Blocker-adjacent items not in this rework (failed handlers 4039, result-schema 4037, human
  dispatch 4036, cache cluster 2163, drain starvation 5010, and the rest of the review's unresolved list) are unchanged.
