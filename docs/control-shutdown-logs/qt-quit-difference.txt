Verified locally, strace -f -k -e trace=unlink on the control-quit scenario
(`control.quit` on an instance started with --control-socket), unlink of
recover.mmp, bottom-up:
    main -> QCoreApplication::exec -> QEventLoop::exec -> processEvents
      -> sendPostedEvents (posted event) -> processApplicationTermination
        -> QApplication::event(Quit) -> QApplication::closeAllWindows()
          -> tryCloseAllWidgetWindows -> QWindow::close()
            -> processCloseEvent -> QWidget::handleClose
              -> MainWindow::closeEvent -> sessionCleanup
                -> ProjectRecovery::removeRecovery -> unlink(recover.mmp)
That chain is the Qt6-only one. The fix does not depend on it.
