aboutToQuit is emitted from QCoreApplicationPrivate::execCleanup(), which
BOTH Qt 5.15 and Qt 6.4 call from exec() after the event loop returns and
BEFORE the deferred deletes that destroy the main window (qt515/qt64
qcoreapplication.cpp, execCleanup()). A forced exit never returns from the
loop at all - the last-resort guard leaves via std::_Exit - so it keeps the
recovery marker, as a non-clean exit must.
