# Developer tooling this fork owns, under tools/ — registered here, and measured by its
# own scope: `--scope tools` on tests/complexity-gate.sh, tests/file-length-gate.sh and
# tests/duplication-gate.sh, with the baselines tests/complexity-baseline-tools.tsv and
# tests/file-length-baseline-tools.tsv. The three scopes have separate baselines and
# cannot shadow each other, exactly as fork/all do.
#
# Why this list exists. `tools/` does not exist upstream of this fork: verified with
# `git ls-tree -r --name-only 4e677cb6c6ab -- tools` (empty) and on upstream master
# (empty), so every file under it is fork-authored by construction. Until this list
# existed both available homes misdescribed such a file:
#   - tests/fork-sources.txt is the C/C++ PRODUCT scope whose ratchets carry per-scope
#     baselines. Registering tooling there widens those ratchets to code that is not
#     product code - measured: tools/mmpz-git/mmpz_git.py is 818 lines (over the 500-line
#     file target) and its functions reach CCN 83, so the fork complexity and file-length
#     gates light up over a tool no product build ever compiles;
#   - tests/upstream-modifications.txt is the UPSTREAM-DIVERGENCE ledger, where each line
#     says "this inherited file diverges, and why". A file upstream has never had cannot
#     be a divergence of inherited code, so an entry there is a false statement about it.
# Gate 9 (tests/fork-sources-gate.sh) reports any tracked source in no scope list; this
# list is the home for the fork's own tooling, so the report has somewhere to point.
#
# Regenerate the candidate set with (base = 4e677cb6c6ab, the upstream commit this fork
# is based on - see the header of tests/fork-sources.txt for why it is not origin/master):
#   git diff --name-only --diff-filter=A 4e677cb6c6ab HEAD -- tools \
#     | grep -E '\.(py|sh|cpp|c|h|hpp|cc|cxx)$' | LC_ALL=C sort
# Verify the entry list below against it. The candidate set also contains the six paths whose
# home is another manifest (named in the paragraph below), so the check subtracts them; this
# must print REPRODUCES and nothing else:
#   diff <(grep -vE '^[[:space:]]*(#|$)' tests/tools-sources.txt | LC_ALL=C sort) \
#     <(git diff --name-only --diff-filter=A 4e677cb6c6ab HEAD -- tools \
#       | grep -E '\.(py|sh|cpp|c|h|hpp|cc|cxx)$' \
#       | grep -vE '^(tools/local-ci\.sh|tools/mmpz-git/scratch/(qtesc|qtroundtrip|qtsave|qtsave2)\.cpp|tools/ncpu-shim\.c|tools/wasm/wat2wasm\.cpp)$' \
#       | LC_ALL=C sort) && echo REPRODUCES
# Nothing else is subtracted - in particular every tools/ path that appears in NO manifest is
# a Gate 9 failure, not an omission from this list. The collation is pinned to C for the same
# reason the other two manifests pin it.
# Members of that set which already have a home are NOT repeated here - one file, one
# home: the four C++ scratch probes (tools/mmpz-git/scratch/*.cpp) and

# file's command subtracts all six.
# Gate 9 accepts membership in any of the three lists, and reports a tools/ source that
