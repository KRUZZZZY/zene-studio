# gigproof — a minimal valid `.gig` for GigPlayer verification

`sine440.gig` is a one-instrument, one-sample GigaStudio file used by
`PluginPortsMigrationTest` to prove that the migrated `GigPlayer` plugin
renders **sample-exactly** the same output as its pre-migration reference
sources.

Without a `.gig` file the harness cannot drive the plugin at all: both the
migrated and the reference host would render silence and the sample-exact
comparison would pass vacuously. The CMake gate in `tests/CMakeLists.txt`
therefore only builds the `gigplayer` harness module when this file (or any
other `sine440.gig` found on the search path) is present, and the test's
`unprovenGaps()` list prints `gigplayer` as UNPROVEN when it is not.

## Contents

| File | What it is |
|------|------------|
| `sine440.gig` | 202.6 KiB, sha256 `138901ce31e994934dada35310a702e4bf96835f1565f5aac71004ecdaa798dc` |
| `make_gig.cpp` | The generator that produced it, using only the libgig write API |

The sample data is a 2 s 440 Hz sine (16-bit mono, 44.1 kHz) with a 5 ms
fade-in and 50 ms fade-out, generated by `make_gig.cpp` itself — no
third-party or copyrighted sample material is included. The file is a test
tone in the public domain.

## Regenerating

Requires `libgig-dev` (Ubuntu: `sudo apt-get install -y libgig-dev`).

```sh
g++ -std=c++17 -O2 make_gig.cpp -o make_gig $(pkg-config --cflags --libs gig)
./make_gig sine440.gig
sha256sum sine440.gig   # expect 138901ce31e994934dada35310a702e4bf96835f1565f5aac71004ecdaa798dc
```

The generator is deterministic: the same libgig version produces the same
bytes (the sample table's CRC-32 entries are derived from the PCM data).

## Verifying independently

`gigdump` comes from the `gigtools` package (not required to build LMMS):

```sh
gigdump --verify sine440.gig   # "All checks passed successfully! :-)"
gigdump sine440.gig            # one instrument "Sine440", one sample "sine440_2s"
```

## Provenance

Created 2026-09-09 for task #589 (Part C slice 8, plugin port migration),
after `find / -xdev -iname '*.gig'` proved no `.gig` file existed anywhere on
the development host. The file was produced locally with libgig 4.3.0 via
`make_gig.cpp`, verified with `gigdump --verify`, and rendered non-silently
by the migrated `GigPlayer` plugin (peak 0.24998 at 44.1 kHz, 0.0 for a
negative control pointing at a non-existent file).
