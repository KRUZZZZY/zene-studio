# tests/rt-safety-scope.txt - the DECLARED audio-thread path set of the
# rt-safety whole-tree sweep (row 52, board card #678).
#
# Format, TAB separated, one path:symbol pair per line:
#
#   <path><TAB><symbol><TAB><reason>[<TAB>rules=<rule-id>[,<rule-id>...]]
#
# * <symbol> is a function definition in <path>: `Class::method`, a free
#   function, or `*` for "every line of this file" (used only for a small
#   header whose whole contents are on the audio thread).
# * The reason states WHY this is an audio-thread path. A blank reason is
#   refused by the sweep (exit 2): a declared path is a claim, and a claim
#   without a reason is a claim nobody can check.
# * The optional rules field narrows a region to named checks; without it, all
#   checks apply. This lets a regression cover one hazard in a callback that
#   already contains unrelated behavior outside the finding.
# * The scope is DECLARED, not discovered: the sweep never follows a call.
#   A path is measured because it is written here, so ADDING A LINE IS THE
#   ACT that widens the programme - and a new audio-thread path that nobody
#   declares is measured by nothing (the sweep's own stated bound).
# * A symbol that no longer resolves is a FAILURE, not a silent skip: the
#   entry is a ledger line and a deleted function invalidates it.
#
# The declared frontier below is the render thread's own path: the backend's
# callback, its four stages, and the fork's realtime-bearing callees that sit
# directly on it. AGENTS.md rule 4: "no allocation, no locking, no unbounded
# growth on audio-thread paths".
