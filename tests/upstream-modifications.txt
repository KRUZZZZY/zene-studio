#   <repo-relative path><TAB><reason>
# The reason is MANDATORY — tests/no-upstream-regression-gate.sh fails (exit 2) on an
# entry with an empty reason, and prints every reason it honours.
#
# POLICY (2026-09-11). Zene Studio is a product, not an upstream patch series. A blanket
# ban on touching inherited code would forbid exactly the work a DAW needs — you cannot
# implement plugin delay compensation without changing the mixer. What this file forbids
# is *undeclared* divergence: a behavioural change to an inherited file that nobody wrote
# down. Every entry here is deliberate and reviewed; anything NOT listed is still a
# violation. Keep each change minimal and local, and ship a test beside it (the gate's
# rule: fork-NEW fixes need a regression test in the same change).
#
# Reasons reference the task/commit that made the change, so a future rebase onto upstream
# can see what this repo owes. When upstream's copy of a file is taken wholesale, delete
# its entry here — an entry that no longer differs from the base is dead weight.
#
# SCOPE (2026-09-12). An entry must be an INHERITED file — one that exists at the fork point
# 4e677cb6c6ab. Fork-authored paths do not belong here: fork-NEW product code is registered in
# tests/fork-sources.txt, and fork tooling under tools/ is registered in
# tests/tools-sources.txt (upstream has no tools/ directory at all). Gate 6 now classifies
# either registration as allowed, so the seven tools/ entries this file used to carry as a
# workaround for its own classifier were deleted — they asserted a divergence of inherited
# code about files upstream has never had.
#

# It never held a line, and Gate 6 was red from the first behavioural change.)
