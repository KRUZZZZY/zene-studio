# Whole-tree scope: every first-party C/C++ source in this repo (not just the fork-NEW set
# in tests/fork-sources.txt). Used by the whole-tree gate run.
#
# The entry list below is the byte-exact output of the command under "Regenerate with", and
# it is this repo's answer to "which C/C++ sources does this product own": upstream LMMS code
# plus everything this fork adds. Fork-NEW sources therefore appear in BOTH manifests by
# design - tests/fork-sources.txt ratchets them as new code, this file measures them beside
# the code they were written against. (docs/CONVENTIONS.md states the definition; until
# 2026-09-12 this file was missing 20 of the fork's own sources, which is what made it
# contradict that definition - see the note under the verify step.)
#
# Vendored third-party trees are excluded on purpose - they are not this repo's code and
# no gate here rewrites them:
#   git submodules (doc/wiki, plugins/LadspaEffect/{calf,cmt,swh,tap}, plugins/CarlaBase/carla,
#     plugins/FreeBoy/game-music-emu, plugins/MidiImport/portsmf, plugins/OpulenZ/adplug,
#     plugins/Sid/resid, plugins/Xpressive/exprtk, plugins/ZynAddSubFx/zynaddsubfx,
#     src/3rdparty/{hiir,jack2,qt5-x11embed,ringbuffer,weakjack})
#   src/3rdparty (85 tracked files), plugins/NeuralAmp/{rtneural,nam,tests},
#   plugins/RnnoiseDenoiser/rnnoise, and tests/reference (verbatim copies of upstream plugin
#   sources kept for A/B comparison - real sources, but duplicates by construction).
#
# Regenerate with (the whole command - no remote state, no arguments):
#   git ls-files '*.c' '*.cc' '*.cpp' '*.cxx' '*.h' '*.hpp' \
#     | grep -vE '^(src/3rdparty/|tests/reference/|plugins/NeuralAmp/(rtneural|nam|tests)/|plugins/RnnoiseDenoiser/rnnoise/)' \
#     | LC_ALL=C sort
#
# Verify it - this must print REPRODUCES and nothing else:
#   diff <(grep -vE '^[[:space:]]*(#|$)' tests/all-sources.txt) \
#        <(git ls-files '*.c' '*.cc' '*.cpp' '*.cxx' '*.h' '*.hpp' \
#            | grep -vE '^(src/3rdparty/|tests/reference/|plugins/NeuralAmp/(rtneural|nam|tests)/|plugins/RnnoiseDenoiser/rnnoise/)' \
#            | LC_ALL=C sort) && echo REPRODUCES
#
# On 2026-09-12 that check printed 20 paths (the Lua console / MIDI-learn / Session View /
# LUFS + loudness-report / script-package sources): every one of them fork-NEW, every one of
# them already registered in tests/fork-sources.txt, and none of them here. Nothing caught it,
# because Gate 9 checks registered->exists and never file->registered. They are in the list
# below now.
#
# The collation is pinned to C deliberately. Plain `sort` follows the caller's locale: under
# en_US.UTF-8 it puts `include/aeffectx.h` before `include/ArrayVector.h`, under C it puts them
# the other way round. An unpinned command therefore reported ~100 spurious line moves on every
# regeneration, which is why this file was never actually re-derived from it. Byte order is
# identical on every machine, which is what makes the verify step above mean something.
